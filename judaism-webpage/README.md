# Judaism: Faith, History, and Tradition

An educational webpage about Judaism for a Religion class group project. Plain HTML, CSS, and JavaScript: no build step, no npm, no accounts or keys.

## Files

```
judaism-webpage/
├── index.html      the whole webpage (all six parts)
├── style.css       design and mobile layout
├── script.js       menu, scroll effects, image backup
├── assets/
│   └── favicon.svg browser tab icon
└── README.md
```

Photos load from Wikimedia Commons, so an internet connection is needed to see them.

## Publish on Netlify (free)

1. Go to https://app.netlify.com/drop and log in or sign up for free (Google or email works).
2. Drag the **`judaism-webpage` folder** (the folder itself, not the files inside it) onto the page. You can also drag the zip file.
3. Wait a few seconds. Netlify gives you a link like `https://random-name-123.netlify.app`.
4. Optional: go to **Site configuration → Change site name** and pick something like `judaism-webpage-period3`. The link becomes `https://judaism-webpage-period3.netlify.app`.
5. Open the link in a private window to make sure it works without being logged in. Submit that link.

To update the site later, open the site in Netlify, go to **Deploys**, and drag the updated folder into the upload box.

## Before you submit

- Add your group's names in the footer. Search `index.html` for `A Religion class group project`.
- Part 6 must quote the textbook or the Canvas resources. This page quotes the Bible (NABRE), the *Catechism of the Catholic Church*, and *Nostra Aetate*. If your teacher only accepts sources from the Canvas page, replace those quotes.
